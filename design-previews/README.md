# Pratonton reka bentuk portfolio

Folder ini mengandungi mockup visual sahaja. Tiada perubahan routing, komponen aplikasi atau laman live dibuat untuk menghasilkan pratonton ini.

A — Modern Dark: pengenalan kiri, potret kanan, projek dalam susunan editorial.
B — Clean Light: latar cerah, gambar di kiri, biodata dan pengalaman di kanan.
C — Editorial: tajuk nama besar, layout berasaskan tipografi dan senarai kerja.

Semua menggunakan biodata yang dibekalkan pengguna. Tempoh pengalaman pembangunan 5 tahun dan freelance 3 tahun dipaparkan berasingan. Flutter ialah kemahiran mobile yang dinyatakan pengguna. DevOps dan AI automation kekal bidang penerokaan. Projek contoh dilabel sebagai konsep demo; tiada pelanggan, metrik atau pautan projek palsu.

Fail HTML boleh dibuka terus dalam pelayar. Fail PNG dijana menggunakan Chromium tempatan. Font menggunakan Arial untuk dua arah moden dan Georgia untuk tajuk editorial; tiada font atau imej luar dimuat turun.

Gambar asal tidak diubah. portrait.webp ialah salinan crop khusus pratonton.
